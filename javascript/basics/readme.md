# JavaScript Basics

One-file tour of the JavaScript fundamentals worth having muscle memory for.

## Key concepts

- Regular expressions and `String.replace`
- The event loop: call stack vs. the Web API environment
- IIFE (Immediately Invoked Function Expression) and scope isolation
- Callbacks vs. promises for async work
- Closures and currying

## Run it

```bash
npm install
npm start        # or: node index.js
```
