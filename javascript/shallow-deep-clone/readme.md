# Shallow Copy vs. Deep Clone

Why spreading an object only copies one level, and how to clone properly.

## Key concepts

- Spread / `Object.assign` = shallow copy
- Reference sharing and the classic "mutating a nested object" bug
- `structuredClone` vs. `JSON.parse(JSON.stringify(...))`
