# Array Method Polyfills

Hand-rolled `map`, `filter` and `reduce` — and how `map` differs from `forEach`.

## Key concepts

- Implementing `map` / `filter` / `reduce` from scratch
- The accumulator and initial value in `reduce`
- `map` returns a new array, `forEach` mutates in place

## Run it

```bash
npm install
npm start        # or: node index.js
```
