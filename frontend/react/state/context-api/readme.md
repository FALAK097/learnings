# Context API

Sharing theme state down the tree without prop drilling.

## Key concepts

- Creating a context and a provider
- Consuming with `useContext` / a custom hook
- Provider value memoisation

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.jsx`
- `src/assets`
- `src/components`
- `src/contexts`
- `src/index.css`
- `src/main.jsx`
