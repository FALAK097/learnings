# Redux Toolkit Blog

A blog app with separate `posts` and `users` slices and cross-slice selectors.

## Key concepts

- Multiple slices and entity adapters
- Selecting across slices
- Async thunk-style data loading
- Relative time formatting with `date-fns`

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
