# Redux Toolkit

A todo list built with `createSlice`, `configureStore` and typed actions.

## Key concepts

- Slices, reducers and actions
- The store and `Provider`
- Selecting state and dispatching actions

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
