# Undoable Counter

A counter that keeps an undo *and* a redo stack of actions.

## Key concepts

- History and redo stacks
- Undoing to a previous value
- Immutable history entries

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
