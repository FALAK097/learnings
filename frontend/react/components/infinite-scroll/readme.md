# Infinite Scroll

Loading more items automatically as the user reaches the bottom.

## Key concepts

- Intersection Observer
- Scroll event + threshold
- Appending pages without duplicating state

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.jsx`
- `src/assets`
- `src/components`
- `src/index.css`
- `src/main.jsx`
