# Checkout Stepper

A multi-step checkout flow with a shared step definition.

## Key concepts

- Defining steps as data
- Rendering a stepper header
- Driving step content from the current index

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.css`
- `src/app.jsx`
- `src/components`
- `src/index.css`
