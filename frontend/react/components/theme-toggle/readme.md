# Theme Toggle

Dark/light mode persisted to `localStorage`.

## Key concepts

- Lazy `useState` initialiser reading `localStorage`
- Persisting state with `useEffect`
- Inline style switching between themes

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.

- `src/app.jsx`
- `src/assets`
