# Image Gallery

A gallery grid that opens a larger view of the selected image.

## Key concepts

- Rendering a list of images
- Selected-item state
- Conditional rendering for the lightbox

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.jsx`
- `src/components`
- `src/index.css`
- `src/main.jsx`
