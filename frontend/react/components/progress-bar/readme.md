# Progress Bar

An animated progress bar that fills to a given percentage.

## Key concepts

- Animating width with a CSS transition
- Clamping the percentage
- Bootstrap React components

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.jsx`
- `src/assets`
- `src/components`
- `src/index.css`
- `src/main.jsx`
