# Drag & Drop

Moving notes around the screen with native HTML5 drag events.

## Key concepts

- `draggable`, `onDragStart`, `onDragOver`, `onDrop`
- Tracking the dragged element with `useState`
- Swap-on-drop update pattern

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
