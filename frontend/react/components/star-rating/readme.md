# Star Rating

An interactive star rating widget.

## Key concepts

- Controlled inputs
- Hover preview vs. committed value
- Array-driven icon rendering

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.

- `src/app.css`
- `src/app.jsx`
- `src/assets`
