# Holy Grail Layout

The classic three-column layout — header, sidebar, main, footer.

## Key concepts

- CSS Grid: `grid-template-areas`
- Flexbox as an alternative
- Responsive behaviour of each approach

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.jsx`
- `src/assets`
- `src/index.css`
- `src/main.jsx`
