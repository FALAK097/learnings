# Sort List

Reordering a list by dragging one person onto another.

## Key concepts

- `useRef` for values that must not trigger a re-render
- Swap-on-hover ordering
- Immutability when reordering arrays

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
