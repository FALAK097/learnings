# React Components

Single-feature UI exercises built with Vite + React. Each folder is a standalone app — install
and run it on its own.

```bash
cd frontend/react/components/<project>
npm install
npm run dev
```

| Project | What it demonstrates |
| --- | --- |
| [counter-app](./counter-app/) | `useState` and the smallest possible React app |
| [drag-and-drop](./drag-and-drop/) | HTML5 drag events, moving notes around |
| [emi-calc](./emi-calc/) | Mortgage calculator (amortisation formula) |
| [faq](./faq/) | Expand/collapse accordion from a data array |
| [holy-grail](./holy-grail/) | The classic three-column layout with CSS Grid |
| [image-gallery](./image-gallery/) | Grid of images with a lightbox view |
| [infinite-scroll](./infinite-scroll/) | Loading more on scroll (Intersection Observer) |
| [like-button](./like-button/) | Like button with SVG icons and optimistic UI |
| [modal-overlay](./modal-overlay/) | Modal dialog with a backdrop |
| [pagination](./pagination/) | Paginated list + live search against a public API |
| [pagination-rc](./pagination-rc/) | Server-driven pagination with `axios` |
| [progress-bar](./progress-bar/) | Animated progress bar |
| [search-filter](./search-filter/) | Live search with a custom `useUsers` hook |
| [sort-list](./sort-list/) | Reordering a list by dragging |
| [star-rating](./star-rating/) | Interactive star rating widget |
| [stepper](./stepper/) | Multi-step checkout flow |
| [theme-toggle](./theme-toggle/) | Dark/light mode persisted to `localStorage` |
| [todo-list](./todo-list/) | Add / edit / delete tasks |
| [undoable-counter](./undoable-counter/) | Counter with undo **and** redo stacks |

See also [forms](../forms/), [hooks](../hooks/) and [state](../state/).
