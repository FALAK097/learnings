# FAQ Accordion

Expand/collapse question and answer list built from a plain data array.

## Key concepts

- Mapping over a data file
- Toggling open/closed state per item
- Extracting a reusable `FaqItem` component

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
