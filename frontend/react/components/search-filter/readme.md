# Search & Filter

Live user search with a reusable `useUsers` hook for the data layer.

## Key concepts

- Extracting data fetching into a custom hook
- Filtering a list as the user types
- Separating the search input from the result list

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
