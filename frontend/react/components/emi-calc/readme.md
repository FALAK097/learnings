# EMI Calculator

Mortgage payment calculator: principal, interest rate and term in, monthly payment out.

## Key concepts

- The amortisation formula
- Deriving monthly rate and number of periods
- Parsing and validating numeric input

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
