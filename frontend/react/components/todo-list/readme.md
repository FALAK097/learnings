# Todo List

Add, edit and delete tasks — the classic CRUD-in-React exercise.

## Key concepts

- Immutable array updates (spread + `splice`)
- Editing by index
- Controlled input with `Enter` to submit

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.

## Files

- `src/app.jsx`
- `src/assets`
- `src/index.css`
- `src/main.jsx`
