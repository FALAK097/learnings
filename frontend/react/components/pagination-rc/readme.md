# Pagination (Remote)

Server-driven pagination: skip/limit against a real API, with `axios`.

## Key concepts

- `skip` / `limit` pagination
- Total page count from the response
- Disabled previous/next states at the boundaries

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
