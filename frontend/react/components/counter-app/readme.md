# Counter App

The smallest possible React counter — the "hello world" of state updates.

## Key concepts

- `useState` and the setter function
- Functional vs. direct state updates
- Batching multiple `setState` calls

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.jsx`
- `src/assets`
- `src/index.css`
- `src/main.jsx`
