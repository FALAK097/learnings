# useMemo Hook

Caching an expensive calculation so it only re-runs when its inputs change.

## Key concepts

- `useMemo` and its dependency array
- The difference between `useMemo` and `useCallback`
- When memoising is worth it

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
