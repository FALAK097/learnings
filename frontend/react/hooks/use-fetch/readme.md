# useFetch Hook

A small data-fetching hook with loading and error state.

## Key concepts

- Splitting `loading` / `error` / `data` state
- Cleanup on unmount
- Refetching

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.jsx`
- `src/assets`
- `src/index.css`
- `src/main.jsx`
- `src/use-fetch.js`
