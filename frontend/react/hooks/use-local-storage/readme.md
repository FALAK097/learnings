# useLocalStorage Hook

A `useState` that transparently persists to `localStorage`.

## Key concepts

- Reading and parsing the stored value
- Writing on every change
- Generic typing with TypeScript
- See [the notes](../../../docs/notes/use-local-storage.md)

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.

- `src/app.tsx`
