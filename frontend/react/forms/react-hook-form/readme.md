# React Hook Form

The same form built three ways: plain RHF, with Yup, and with Zod.

## Key concepts

- `useForm`, `register`, `handleSubmit`
- Resolvers: `@hookform/resolvers`
- Schema validation with Yup and Zod
- MUI integration

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.
