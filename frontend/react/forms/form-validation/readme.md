# Form Validation

Client-side validation with per-field error messages.

## Key concepts

- Validation rules per field
- Touched / dirty tracking
- Disabling submit until valid

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.jsx`
- `src/assets`
- `src/form.jsx`
- `src/index.css`
- `src/main.jsx`
