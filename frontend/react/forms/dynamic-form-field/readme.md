# Dynamic Form Fields

Adding and removing inputs at runtime.

## Key concepts

- Array of field objects in state
- Immutable insert/remove with `splice`
- Index-based change handling

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # eslint
```

> Each project is self-contained: run the commands **inside the project folder**.


## Files

- `src/app.css`
- `src/app.jsx`
- `src/index.css`
