# Frontend

Everything browser-side lives here.

```
frontend/
└── react/
    ├── components/   # single-feature UI exercises
    ├── forms/        # form handling and validation
    ├── hooks/        # custom hooks
    └── state/        # context, redux toolkit
```

Each project is a standalone Vite app with its own `package.json` — there is no monorepo
install. Navigate into a project and run:

```bash
npm install
npm run dev
```
