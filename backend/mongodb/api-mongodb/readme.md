# Express + MongoDB API

A typed Express API on Mongoose with authentication, sessions and role checks.

## Key concepts

- Mongoose models and schemas
- User registration and login
- Session tokens and auth middleware
- Owner-only route guards
- `cors`, `compression`, `cookie-parser` middleware

## Run it

```bash
npm install
npm start        # or: node index.js
```


## Files

- `src/controllers`
- `src/db`
- `src/helpers`
- `src/index.ts`
- `src/middlewares`
- `src/router`
